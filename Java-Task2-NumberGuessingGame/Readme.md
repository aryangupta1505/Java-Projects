Task 2: Number Guessing Game

A GUI-based number guessing game developed in **Java Swing** where players attempt to guess a randomly generated secret number within a limited number of tries[cite: 2].

Key Features
* **Difficulty Modes:** Supports **Easy** (`1–50`, 10 attempts), **Medium** (`1–100`, 7 attempts), and **Hard** (`1–200`, 5 attempts)[cite: 2].
* **Real-Time Feedback:** Evaluates each guess and provides immediate `"Too High!"`, `"Too Low!"`, or `"Correct!"` feedback[cite: 2].
* **Attempt Tracking & Win/Loss Logic:** Displays a live attempt counter throughout the round and reveals the target number with a `"You Lost!"` alert if the attempt limit is reached[cite: 2].
* **Multi-Round Scoreboard:** Logs performance across consecutive rounds (e.g., *"Round X — guessed in Y attempts"*)[cite: 2].
* **Continuous Replay:** Includes a `"Play Again"` prompt and button after every round for seamless replayability[cite: 2].

Tech Stack
* **Language:** Java (`java.util.Random`)
* **GUI Framework:** Java Swing
